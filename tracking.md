# Minutes Collection Tracker

Tracks what's been pulled into `Minutes/` per board/commission per month, so future pulls only need to chase gaps.

**Legend**
- ✅ = approved minutes on file
- — = nothing on file for that month
- Cell text gives the meeting date(s) within the month

Compiled 2026-09-09, covering months with files in `Minutes/`: 2026-06 through 2026-09 (September is partial — month in progress at pull time).

**Policy update 2026-09-11:** This project no longer pulls or tracks agendas — only approved minutes. Cells that previously showed an agenda-only status (📋) now show `—` regardless of whether an agenda exists on the source website; the tracker only records whether minutes are on file. Agenda files already downloaded under the old process remain in `Minutes/` but are no longer tracked here.

## How to use this

1. Any `—` cell is a candidate to check on the next pull — either the board didn't meet that month, or minutes exist but weren't collected yet. This tracker doesn't distinguish those two cases, and no longer distinguishes "agenda posted, minutes pending" either — only whether minutes are on file.
2. September is still in progress as of the 2026-09-09 compile date — most `—` cells there are simply "hasn't happened yet," not a gap.
3. Two boards turned up in `Minutes/` that aren't in `references.md` (Kingston Springs Wastewater Board, Pleasant View Beer Board) — worth adding to that reference doc.
4. NES's `—` cells for Jun–Sep 2026 specifically mean "not backfilled by instruction," not "checked and empty" — don't treat them the same as other boards' gaps.
